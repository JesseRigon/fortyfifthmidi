# Lore

## What actually happened

I named the plugin **fortyfifthmidi** without thinking about it much. It just
sounded good.

Later I asked an AI for some plausible backstory for the name, and it produced
the three origin stories below. I have no idea whether any of it is true — none
of it has been verified. But I liked the name more afterwards, so the name
stays and so does this file.

Everything past this line is invented until proven otherwise.

---

## The Lost Note

MIDI note 45 is A2, which sits at exactly 110 Hz, one of the only notes in the
standard tuning grid that lands on a clean whole number. The story goes that an
early synth engineer noticed that A2 always sounded slightly "more in tune"
than everything around it on a particular prototype keyboard, as if the
hardware liked it better. Nobody could reproduce it on other units. The
prototype was scrapped, but a handful of technicians kept calling that phantom
sweetness "the forty-fifth." The plugin is supposedly an attempt to find it
again.

## The Undefined Controller

In the MIDI spec, CC 45 is technically the fine-resolution partner of CC 13, a
controller that was never assigned any official purpose. So CC 45 is a knob
attached to nothing: a precision adjustment for a parameter that doesn't exist.

Lore version: a small group of 90s tracker musicians started mapping CC 45 to
whatever they considered the "secret" parameter in each patch, the one you'd
never tell anyone about. Sending someone a file with CC 45 automation was a
kind of handshake. fortyfifthmidi is what you'd get if that knob finally got a
job.

## The 45 That Wasn't Pressed

7-inch singles spin at 45 RPM. The rumour is that a small label in the early
80s tried to release a single that existed only as a MIDI file on floppy, with
a sleeve and everything, pitched as "the forty-fifth" because it was meant to
be played at home through your own synths rather than a turntable. It sold
almost nothing, the floppies degraded, and no one has a working copy. People
who claim to have heard it all describe it differently, which is exactly the
point: the sound depends on whatever gear you run it through.

## The short version, for an about page

> fortyfifthmidi is named after the controller no one assigned, the note that
> sits on a perfect 110, and a single that was never pressed. We're not sure
> which one is true. Possibly all three.
